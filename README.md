# ProtMate
ProtMate: A System for Performing Biochemical &amp; Biophysical Calculations<br>
![ProtMate_logo](https://github.com/user-attachments/assets/1e268cdd-8b93-44f0-9af6-97b000b9bdf9)
<br>

<p>ProtMate is a UNIX application for performing common laboratory calculations, focusing primarily on biochemical and biophysical workflows.</p>

<p>Pre-compiled binarries for MacOS (verision 15.2 and above) are provided). Additional binaries for Linux distributions will be made available in the future. Alternatively, the source-code can be compiled using the GNU C++ compiler in any UNIX or Linux environment (including the Windows Subsusyem for Linux) using the following command:</p>

  <pre>g++ -o protmate &lt;location of src file&gt;/pmate.cpp</pre>
